介绍

坏枪随机器源自2021年，是可以进行随机抽取元素的软件，最初由 Python 编写，现重写为 HTML 版。

在这里，你只需要将含有抽取元素的 xls 或 xlsx 文件点击底下的“上传”按钮进行上传，即可导入自定义抽取列表。

目前对空白单元格已经进行了过滤。

在你使用完毕后，若想要导出抽取结果，可以点击“导出”按钮。你将得到一份 txt 文件。

音效来源

此版本的随机器音效由坏枪本人制作。

网络存储 / Cookie 使用

如果您是由B站Toy访问，那么您的抽取名单会被上传至B站的云存储，下次打开可继续使用。

如果您是通过其他方式访问，我们会将您的元素列表存储为 Cookie，如果不清除则永久不过期。
