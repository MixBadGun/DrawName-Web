# 坏枪随机器
**坏枪随机器**是一款随机抽取工具。前三代由 Tkinter 构建，第四代由 Kivy 构建。

目前的第五代由 HTML + Javascript 构建。

## 功能介绍
用户可以上传自己的 xls 或 xlsx 文件，随机器将读取其中的所有单元格，并对抽取格的个数进行调整。这些信息将存储在用户浏览器 Cookie 当中，不会上传到服务器。

随机器的元素抽取采用“老虎机式”模式。所抽取的元素将按字符分离。随机器在启动时，不会立即显示所抽取元素，而将根据抽取列表内**前缀是否仍有重复元素**依次跳出：多个候选项共有的部分会一次性展示，一旦只剩下唯一结果，余下的字符也会一并展示。

每揭示一个字符，它都会带着与前一字符之间的空隙融入第一个方框，方框随后收拢，最终由同一个矩形包住整段文字。

此模式适用于姓氏相同或相似名称的抽取，更有助于营造“刺激”的氛围。

## 构建与部署
需要 Node.js 18 及以上。

```bash
npm install     # 首次安装构建依赖
npm run build   # 生成 dist/
npm run preview # 构建并在 http://127.0.0.1:8080 预览
```

构建会压缩 JS / CSS / HTML（去除注释、多余空白与引号）、按显示尺寸重新压缩 WebP 动画帧，并把 `image/`、`sound/` 等静态资源拷贝到 `dist/`。把 `dist/` 整个目录上传到静态服务器即可部署；加 `--no-images` 可跳过图片压缩：`node build.mjs --no-images`。
